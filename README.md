# כפתור ופרח – "מה העלה מספר לנו?"

יחידת לימוד רספונסיבית בעברית למשתלת כפתור ופרח (קורס תכנות 3, קבוצה 15).

- `index.html` – העמוד
- `css/style.css` – כל ה-CSS של האתר
- `js/main.js` – ה-JavaScript של האתר
- `images/` – תמונות
- `ai-usage-log.md` – נספח תיעוד השימוש ב-AI
- `copyright.md` – טיוטת דוח זכויות יוצרים וקרדיטים

פרסום: GitHub Pages. בהמשך גם חבילת SCORM ל-LMS.

## הרצה מקומית
פותחים את `index.html` בדפדפן (ב-Rider: לחיצה ימנית › Open In › Browser). מדריך הבדיקה נמצא בקובץ `TESTING.md`.

## ספריות חיצוניות (CDN)
Bootstrap 5.3.3 (בגרסת RTL), SortableJS 1.15.2 (גרירה במשחק המיון), Google Fonts (Heebo ו-Rubik).

## Cache-busting
בכל שינוי ב-CSS או ב-JS מעלים את מספר הגרסה (למשל `?v=2.2.0`) בקישורים שב-`index.html`.
